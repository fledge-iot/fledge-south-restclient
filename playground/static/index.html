User functions

Top-level defs become JMESPath functions on this engine (same hook as flatten()). Used by Expression, and by Mapping when the YAML has no functions: block. json, re, math, datetime are already in scope.

flatten identity keys are names, not field lookups. Write flatten(from_json(value[0].Data), ['SiteId', 'LineId', 'EquipmentId']) (single quotes; default separator _). An optional third argument sets the separator (flatten(..., ['SiteId'], '.')). Double quotes like ["SiteId"] are rewritten to string literals.
